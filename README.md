# Enterprise-Network-Infrastructure

## Enterprise Network Design, Implementation & Security

This project demonstrates the design and implementation of a secure enterprise network infrastructure across multiple buildings using Cisco networking technologies and security best practices.

### Features

* VLAN Segmentation
* Inter-VLAN Routing
* DHCP Services
* DNS Services
* NAT Configuration
* Access Control Lists (ACLs)
* Port Security
* SSH Remote Management
* Telnet Configuration
* HSRP/VRRP Redundancy
* FTP Services
* HTTP Services
* Multi-Building Network Architecture
* High Availability and Redundancy

### Technologies Used

* Cisco Packet Tracer
* Cisco IOS
* Routing & Switching
* Network Security
* VLANs
* DHCP
* DNS
* NAT
* ACLs
* HSRP/VRRP

### Project Components

* 3 Buildings
* 3 Floors per Building
* 9 VLANs
* 6 Multilayer Switches
* 9 Access Switches
* 3 Edge Routers

### Network Services

* DHCP
* DNS
* FTP
* HTTP

### Security Features

* ACL-Based Access Control
* Port Security
* Secure Remote Management (SSH)
* Network Segmentation using VLANs
* NAT for Internet Access

* Enterprise Network Documentation
